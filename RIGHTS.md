## Post-release notice review

The optional fuzz lock has a separate dependency graph; its exact package/version
pairs and upstream notices are included in THIRD_PARTY_INVENTORY.json. r-efi's
previously omitted AUTHORS file contains its license alternatives and original
authors and is now retained from upstream v6.0.0. crc32c still lacks standalone
license files in the archive and pinned upstream source; its original README and
metadata grant MIT/Apache alternatives. This is a documented upstream notice gap,
not a newly manufactured copyright notice or a guarantee of redistribution rights.

libfuzzer-sys declares NCSA in registry metadata, while packaged LLVM C++ headers
state Apache-2.0 WITH LLVM-exception. Both declarations and the full official LLVM
license (including legacy NCSA terms) are retained with pinned upstream provenance.
Only project fuzz harness source and lockfiles are distributed, with no vendored
fuzzer source, corpora or compiled binaries. Compilation is not a fuzz campaign.
